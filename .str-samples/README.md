# Muestras de `lotr.str`

Ficheros reales de Age of the Ring para los tests de `src/lib/translations/str.test.ts`.
No se suben al repositorio. Nómbralos `<idioma>-<versión>.str`, por ejemplo
`en-9.3.3.str` (original) y `es-9.3.3.str` (traducción de la comunidad).
Si no están, los tests que los usan se saltan.
